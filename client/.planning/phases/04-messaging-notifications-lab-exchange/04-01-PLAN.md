    - getUnreadCount() → $fetch GET /api/v1/messages/unread-count, typed UnreadCountResponse

    useLabApi must expose:
    - listLabResults(clientId: string, page?: number, pageSize?: number) → useAsyncData GET /api/v1/clients/:id/lab-results
    - uploadLabResult(clientId: string, req: UploadLabResultRequest) → $fetch POST /api/v1/clients/:id/lab-results with FormData (title, result_type, test_date?, notes?, file? or link?)
    - getDownloadUrl(labId: string) → returns string "/api/v1/lab-results/:id/download" (no fetch — browser handles redirect or file attachment)

    - getPreferences() → useAsyncData GET /api/v1/notifications/preferences, typed NotificationPreferences
    - updatePreferences(req: UpdateNotificationPreferencesRequest) → $fetch PATCH /api/v1/notifications/preferences
