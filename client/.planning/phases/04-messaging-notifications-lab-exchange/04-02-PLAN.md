## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MessageComposeBar → sendClientMessage | User-supplied file and text cross client→API boundary |
| client-offline store → replay plugin | Queued message payload replayed to POST /messages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | MessageComposeBar file picker | mitigate | Validate file.size and file.type client-side before FormData; reject non-image/non-PDF MIME types with Persian error |
| T-04-02-02 | Denial of Service | Polling interval | mitigate | Single interval per component mount; clearInterval on unmount prevents accumulation of intervals on navigation |
| T-04-02-03 | Tampering | Offline queue message payload | accept | Payload content is user's own message text; no privilege escalation possible; backend validates sender identity via Bearer token |
| T-04-02-04 | Information Disclosure | cachedMessages in Pinia store | accept | Messages are from the authenticated user's own conversation; store is client-side only, cleared on logout via existing Phase 2 logout semantics |
</threat_model>
