## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser token state -> auth API | Untrusted client runtime must not bypass token lifecycle rules. |
| API error payload -> UI messaging | Backend error payloads must be sanitized into controlled user-safe messages. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | S | auth session store | mitigate | Keep role and token pair in typed store with explicit refresh-token ownership checks before refresh replay. |
| T-02-02 | T | auth fetch plugin | mitigate | Gate retries behind single-flight refresh promise and reject tampered refresh outputs that fail contract parsing. |
| T-02-03 | I | error mapping layer | mitigate | Map API codes to curated Persian messages and block direct render of backend message fields. |
| T-02-04 | D | refresh endpoint usage | mitigate | Coalesce concurrent refresh attempts to one in-flight request and fan-out result. |
</threat_model>
