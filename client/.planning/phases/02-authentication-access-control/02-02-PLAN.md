## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OTP/mobile user input -> auth endpoints | Untrusted input must be validated before API calls and UI state transitions. |
| OTP endpoint error codes -> visual notices | Backend error semantics must not leak account or internals. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | S | OTP verify page | mitigate | Bind verification to mobile provided in current flow state and reject cross-flow mismatches before submit. |
| T-02-06 | I | OTP error notices | mitigate | Use fixed Persian error map for OTP_INVALID, OTP_EXPIRED, OTP_MAX_ATTEMPTS, OTP_RATE_LIMIT; never expose raw backend messages. |
| T-02-07 | D | OTP send endpoint usage | mitigate | Enforce client-side cooldown and disabled controls to reduce repeated calls during server throttling windows. |
</threat_model>
