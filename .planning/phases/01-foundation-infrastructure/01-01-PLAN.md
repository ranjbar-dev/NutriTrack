    1. Create migration 000001_create_users per RESEARCH.md code examples:
       **UP:**
       ```sql
       CREATE EXTENSION IF NOT EXISTS "pgcrypto";
       CREATE TYPE user_role AS ENUM ('super_admin', 'nutritionist', 'client');
       CREATE TYPE gender_type AS ENUM ('male', 'female');
       CREATE TABLE users (
           id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
           role user_role NOT NULL,
           full_name VARCHAR(255) NOT NULL,
           email VARCHAR(255) UNIQUE,
           password_hash VARCHAR(255),
           mobile VARCHAR(15) UNIQUE,
           date_of_birth DATE,
           height_cm REAL,
           gender gender_type,
           nutritionist_id UUID REFERENCES users(id),
           is_active BOOLEAN NOT NULL DEFAULT true,
           notes TEXT,
           created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
           updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );
       CREATE INDEX idx_users_mobile ON users (mobile) WHERE mobile IS NOT NULL;
       CREATE INDEX idx_users_nutritionist ON users (nutritionist_id) WHERE role = 'client';
       CREATE INDEX idx_users_email ON users (email) WHERE email IS NOT NULL;
       ```
       **DOWN:** Drop table, types, extension.

    2. Create migration 000002_create_otp_codes per RESEARCH.md:
       **UP:** otp_codes table with id, mobile, code_hash (SHA-256), attempts, max_attempts (default 3), expires_at, verified, created_at. Index on (mobile, expires_at) WHERE verified = false.
       **DOWN:** Drop table.

    3. Create migration 000003_create_refresh_tokens per RESEARCH.md:
       **UP:** refresh_tokens table with id, user_id (FK users ON DELETE CASCADE), token_hash (unique), family_id (for rotation theft detection), expires_at, revoked, created_at. Indexes on user_id (WHERE revoked=false), token_hash (WHERE revoked=false).
       **DOWN:** Drop table.

    4. **CRITICAL — use TIMESTAMPTZ everywhere, never TIMESTAMP** (Pitfall 6 from RESEARCH.md).

    5. Create sqlc.yaml per RESEARCH.md Pattern 5:
       ```yaml
       version: "2"
       sql:
         - engine: "postgresql"
           queries: "db/queries/"
           schema: "db/migrations/"
           gen:
             go:
               package: "sqlc"
               out: "internal/repository/sqlc"
               sql_package: "pgx/v5"
               emit_json_tags: true
               emit_prepared_queries: false
               emit_interface: true
               emit_empty_slices: true
       ```

    6. Create SQL query files per D-09 and D-26 (all parameterized — SEC-03):

       **db/queries/users.sql:**
       - `GetUserByEmail :one` — SELECT * WHERE email = $1 AND is_active = true
       - `GetUserByMobile :one` — SELECT * WHERE mobile = $1 AND is_active = true
       - `GetUserByID :one` — SELECT * WHERE id = $1
       - `CreateUser :one` — INSERT ... RETURNING *
       - `GetClientsByNutritionistID :many` — SELECT WHERE nutritionist_id = $1 AND role = 'client' ORDER BY created_at DESC
       - `UpdateUserActive :exec` — UPDATE users SET is_active = $2, updated_at = NOW() WHERE id = $1

       **db/queries/otp.sql:**
       - `CreateOTP :one` — INSERT (mobile, code_hash, expires_at, max_attempts) RETURNING *
       - `GetActiveOTPByMobile :one` — SELECT WHERE mobile = $1 AND expires_at > NOW() AND verified = false ORDER BY created_at DESC LIMIT 1
       - `IncrementOTPAttempts :exec` — UPDATE SET attempts = attempts + 1 WHERE id = $1
       - `MarkOTPVerified :exec` — UPDATE SET verified = true WHERE id = $1
       - `DeleteExpiredOTPs :exec` — DELETE FROM otp_codes WHERE expires_at < NOW()

       **db/queries/refresh_tokens.sql:**
       - `CreateRefreshToken :one` — INSERT RETURNING *
       - `GetRefreshTokenByHash :one` — SELECT WHERE token_hash = $1 AND revoked = false
       - `RevokeRefreshToken :exec` — UPDATE SET revoked = true WHERE id = $1
       - `RevokeTokenFamily :exec` — UPDATE SET revoked = true WHERE family_id = $1
       - `RevokeUserTokens :exec` — UPDATE SET revoked = true WHERE user_id = $1

    7. Run `sqlc generate` to produce Go code in `backend/internal/repository/sqlc/`.

    8. Verify generated code compiles: `cd backend && go build ./...`
