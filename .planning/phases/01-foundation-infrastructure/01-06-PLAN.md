  <action>
    1. Create `backend/Dockerfile` — multi-stage build per RESEARCH.md and INFRA-01:

       ```dockerfile
       # Stage 1: Build
       FROM golang:1.25-alpine AS builder
       RUN apk add --no-cache ca-certificates git
       WORKDIR /build
       COPY go.mod go.sum ./
       RUN go mod download
       COPY . .
       RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o /app ./cmd/api

       # Stage 2: Run (~20MB final image)
       FROM scratch
       COPY --from=builder /etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/
       COPY --from=builder /app /app
       COPY --from=builder /build/db/migrations /db/migrations
       EXPOSE 8080
       ENTRYPOINT ["/app"]
       ```

       **Key decisions:**
       - `FROM scratch` for minimal attack surface (INFRA-01, SEC-01)
       - `-ldflags="-s -w"` strips debug symbols (~30% size reduction)
       - `CGO_ENABLED=0` for static binary (required for scratch)
       - Copy ca-certificates for HTTPS (Kavenegar API calls)
       - Copy migrations directory (golang-migrate runs them on startup)
       - Go 1.25 per Pitfall 1 (Gin v1.12.0 requires Go 1.25+)

    2. Create `backend/.dockerignore`:
       ```
       .git
       .gitignore
       README.md
       *.md
       .env
       .env.*
       tmp/
       ```

    3. Create `frontend/Dockerfile` — Nuxt 4 production build:

       ```dockerfile
       # Stage 1: Build
       FROM node:22-alpine AS builder
       WORKDIR /build
       COPY package.json package-lock.json ./
       RUN npm ci
       COPY . .
       RUN npm run build

       # Stage 2: Run
       FROM node:22-alpine
       WORKDIR /app
       COPY --from=builder /build/.output .output
       ENV HOST=0.0.0.0
       ENV PORT=3000
       ENV NODE_ENV=production
       EXPOSE 3000
       CMD ["node", ".output/server/index.mjs"]
       ```

       **Key decisions:**
       - Node 22 Alpine for small image
       - `npm ci` for reproducible builds
       - Copy only `.output/` to production stage
       - Nuxt 4 outputs to `.output/` directory

    4. Create `frontend/.dockerignore`:
       ```
       .git
       .gitignore
       node_modules
       .nuxt
       .output
       README.md
       *.md
       .env
       .env.*
       ```

    1. Create `docker-compose.yml` — production configuration per RESEARCH.md lines 998-1085 and D-19, D-20:

       ```yaml
       version: "3.8"

       services:
         traefik:
           image: traefik:v3.2
           command:
             - "--providers.docker=true"
             - "--providers.docker.exposedbydefault=false"
             - "--entrypoints.web.address=:80"
             - "--entrypoints.websecure.address=:443"
             - "--entrypoints.web.http.redirections.entryPoint.to=websecure"
             - "--entrypoints.web.http.redirections.entryPoint.scheme=https"
             - "--certificatesresolvers.letsencrypt.acme.httpchallenge.entrypoint=web"
             - "--certificatesresolvers.letsencrypt.acme.email=${ACME_EMAIL}"
             - "--certificatesresolvers.letsencrypt.acme.storage=/letsencrypt/acme.json"
           ports:
             - "80:80"
             - "443:443"
           volumes:
             - /var/run/docker.sock:/var/run/docker.sock:ro
             - letsencrypt:/letsencrypt
           restart: unless-stopped

         api:
           build:
             context: ./backend
             dockerfile: Dockerfile
           env_file: .env
           labels:
             - "traefik.enable=true"
             - "traefik.http.routers.api.rule=Host(`${DOMAIN}`) && PathPrefix(`/api`)"
             - "traefik.http.routers.api.entrypoints=websecure"
             - "traefik.http.routers.api.tls.certresolver=letsencrypt"
             - "traefik.http.services.api.loadbalancer.server.port=8080"
           depends_on:
             postgres:
               condition: service_healthy
           restart: unless-stopped

         frontend:
           build:
             context: ./frontend
             dockerfile: Dockerfile
           env_file: .env
           labels:
             - "traefik.enable=true"
             - "traefik.http.routers.frontend.rule=Host(`${DOMAIN}`)"
             - "traefik.http.routers.frontend.entrypoints=websecure"
             - "traefik.http.routers.frontend.tls.certresolver=letsencrypt"
             - "traefik.http.services.frontend.loadbalancer.server.port=3000"
             - "traefik.http.routers.frontend.priority=1"
           restart: unless-stopped

         postgres:
           image: postgres:16-alpine
           environment:
             POSTGRES_DB: ${POSTGRES_DB}
             POSTGRES_USER: ${POSTGRES_USER}
             POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
           volumes:
             - pgdata:/var/lib/postgresql/data
           healthcheck:
             test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER} -d ${POSTGRES_DB}"]
             interval: 5s
             timeout: 5s
             retries: 5
           restart: unless-stopped

       volumes:
         pgdata:
         letsencrypt:
       ```

       **CRITICAL routing per D-19, D-20:**
       - API router has `PathPrefix('/api')` — matches first due to Traefik priority (longer prefix = higher priority)
       - Frontend router has `Host` only with `priority=1` — catches all other paths
       - Both on same domain — cookies work with SameSite=Strict (Pitfall 4 resolved)
       - HTTP→HTTPS redirect enabled via entrypoint redirection

    2. Create `docker-compose.dev.yml` — development override:

             POSTGRES_DB: ${POSTGRES_DB:-nutritrack}
             POSTGRES_USER: ${POSTGRES_USER:-nutritrack}
             POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-devpassword}
           volumes:

           healthcheck:

             interval: 5s
             timeout: 5s
             retries: 5

         pgdata_dev:

<task type="auto">
  <name>Task 3: GitLab CI/CD pipeline</name>
  <files>
    .gitlab-ci.yml
  </files>
  <action>
    Create `.gitlab-ci.yml` per RESEARCH.md lines 1088-1182 and D-21:

    ```yaml
    stages:
      - lint
      - test
      - build
      - deploy

    variables:
      GO_VERSION: "1.25"
      NODE_VERSION: "22"

    # ── Lint Stage ──

    lint:backend:
      stage: lint
      image: golang:${GO_VERSION}-alpine
      script:
        - cd backend
        - go vet ./...
        - |
          if command -v golangci-lint &> /dev/null; then
            golangci-lint run
          else
            echo "golangci-lint not installed, skipping"
          fi
      rules:
        - changes:
            - backend/**/*

    lint:frontend:
      stage: lint
      image: node:${NODE_VERSION}-alpine
      script:
        - cd frontend
        - npm ci
        - npx nuxi typecheck
      cache:
        key: frontend-${CI_COMMIT_REF_SLUG}
        paths:
          - frontend/node_modules/
      rules:
        - changes:
            - frontend/**/*

    # ── Test Stage ──

    test:backend:
      stage: test
      image: golang:${GO_VERSION}-alpine
      services:
        - name: postgres:16-alpine
          alias: postgres
      variables:
        POSTGRES_DB: nutritrack_test
        POSTGRES_USER: nutritrack
        POSTGRES_PASSWORD: testpassword
        DATABASE_URL: "postgres://nutritrack:testpassword@postgres:5432/nutritrack_test?sslmode=disable"
        JWT_SECRET: "test-jwt-secret-minimum-32-characters"
        ENVIRONMENT: "test"
      script:
        - cd backend
        - go test ./... -v -race -count=1
      rules:
        - changes:
            - backend/**/*

    test:frontend:
      stage: test
      image: node:${NODE_VERSION}-alpine
      script:
        - cd frontend
        - npm ci
        - npm run test --if-present
      cache:
        key: frontend-${CI_COMMIT_REF_SLUG}
        paths:
          - frontend/node_modules/
      rules:
        - changes:
            - frontend/**/*

    # ── Build Stage ──

    build:backend:
      stage: build
      image: docker:24
      services:
        - docker:24-dind
      variables:
        DOCKER_TLS_CERTDIR: "/certs"
      script:
        - docker build -t ${CI_REGISTRY_IMAGE}/api:${CI_COMMIT_SHORT_SHA} ./backend
        - docker tag ${CI_REGISTRY_IMAGE}/api:${CI_COMMIT_SHORT_SHA} ${CI_REGISTRY_IMAGE}/api:latest
        - docker login -u ${CI_REGISTRY_USER} -p ${CI_REGISTRY_PASSWORD} ${CI_REGISTRY}
        - docker push ${CI_REGISTRY_IMAGE}/api:${CI_COMMIT_SHORT_SHA}
        - docker push ${CI_REGISTRY_IMAGE}/api:latest
      rules:
        - if: $CI_COMMIT_BRANCH == "main"

    build:frontend:
      stage: build
      image: docker:24
      services:
        - docker:24-dind
      variables:
        DOCKER_TLS_CERTDIR: "/certs"
      script:
        - docker build -t ${CI_REGISTRY_IMAGE}/frontend:${CI_COMMIT_SHORT_SHA} ./frontend
        - docker tag ${CI_REGISTRY_IMAGE}/frontend:${CI_COMMIT_SHORT_SHA} ${CI_REGISTRY_IMAGE}/frontend:latest
        - docker login -u ${CI_REGISTRY_USER} -p ${CI_REGISTRY_PASSWORD} ${CI_REGISTRY}
        - docker push ${CI_REGISTRY_IMAGE}/frontend:${CI_COMMIT_SHORT_SHA}
        - docker push ${CI_REGISTRY_IMAGE}/frontend:latest
      rules:
        - if: $CI_COMMIT_BRANCH == "main"

    # ── Deploy Stage ──

    deploy:production:
      stage: deploy
      image: alpine:latest
      before_script:
        - apk add --no-cache openssh-client
        - eval $(ssh-agent -s)
        - echo "${SSH_PRIVATE_KEY}" | ssh-add -
        - mkdir -p ~/.ssh
        - echo "${SSH_KNOWN_HOSTS}" >> ~/.ssh/known_hosts
      script:
        - |
          ssh ${DEPLOY_USER}@${DEPLOY_HOST} << 'DEPLOY'
            cd /opt/nutritrack
            docker compose pull
            docker compose up -d --remove-orphans
            docker image prune -f
          DEPLOY
      environment:
        name: production
        url: https://${DOMAIN}
      rules:
        - if: $CI_COMMIT_BRANCH == "main"
          when: manual
      needs:
        - build:backend
        - build:frontend
    ```

    **Pipeline design per D-21:**
    - **4 stages:** lint → test → build → deploy (INFRA-03)
    - **Conditional execution:** Backend/frontend jobs only run when their files change (`rules.changes`)
    - **Build/deploy only on main:** Feature branches get lint + test only
    - **Deploy is manual:** Requires explicit click in GitLab UI (safety gate)
    - **PostgreSQL service** in test stage for integration tests with real DB
    - **Docker-in-Docker** for image builds using GitLab Container Registry
    - **SSH deployment:** Uses GitLab CI/CD variables for SSH key + host (INFRA-02)

    **Required GitLab CI/CD variables (set in GitLab UI → Settings → CI/CD → Variables):**
    - `SSH_PRIVATE_KEY` — Deploy key for production server
    - `SSH_KNOWN_HOSTS` — Production server host fingerprint
    - `DEPLOY_USER` — SSH user on production server
    - `DEPLOY_HOST` — Production server hostname/IP
    - `DOMAIN` — Production domain name

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Traefik | TLS termination point, public entry |
| Traefik → Services | Internal Docker network, unencrypted HTTP |
| CI/CD → Production Server | SSH-based deployment |
| Docker Socket → Traefik | Traefik reads container labels |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | TLS termination | mitigate | Let's Encrypt auto-renewing certs; HTTP→HTTPS redirect enforced (SEC-01) |
| T-06-02 | Tampering | Docker socket | mitigate | Mount docker.sock as read-only (:ro) to Traefik |
| T-06-03 | Information Disclosure | .env file | mitigate | .env in .gitignore; .env.example has placeholder values only |
| T-06-04 | Elevation of Privilege | Container escape | mitigate | FROM scratch for Go (no shell, no OS utilities); minimal Alpine for Node |
| T-06-05 | Denial of Service | Database exposed | mitigate | PostgreSQL not exposed in production compose (internal network only) |
| T-06-06 | Tampering | Deploy pipeline | mitigate | Manual deploy gate; SSH key stored as GitLab CI/CD protected variable |
</threat_model>
