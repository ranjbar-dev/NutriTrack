**frontend/app/stores/food.ts** — Follow auth.ts Pinia pattern with `defineStore('food', () => {...})`:

State:
```typescript
const foods = ref<FoodResponse[]>([])
const currentFood = ref<FoodResponse | null>(null)
const total = ref(0)
const page = ref(1)
const hasMore = ref(false)
const loading = ref(false)
const searchQuery = ref('')
const selectedCategory = ref<string | null>(null)
const showInactive = ref(false)
```

Define TypeScript interfaces at the top of the file:
```typescript
interface FoodResponse { ... } // as shown in interfaces above
interface FoodListResponse { ... }
interface CreateFoodPayload {
  name: string; description?: string; categories: string[];
  calories: number; protein_g: number; carbs_g: number; fat_g: number;
  fiber_g: number; sugar_g: number; sodium_mg: number;
  measurement_unit: string; measurement_amount: number;
}
```

Actions:
1. `fetchFoods(reset = false)` — Builds query string from searchQuery, selectedCategory, showInactive, page. If reset=true, set page=1 and clear foods array. Calls `GET /foods?search=...&category=...&is_active=...&page=...&limit=20`. Appends to foods array (for load more). Updates total, hasMore.
2. `fetchFood(id: string)` — Calls `GET /foods/${id}`. Sets currentFood.
3. `createFood(payload: CreateFoodPayload)` — Calls `POST /foods`. Returns the created food.
4. `updateFood(id: string, payload: CreateFoodPayload)` — Calls `PUT /foods/${id}`.
5. `deleteFood(id: string)` — Calls `DELETE /foods/${id}`. Removes from local foods array.
6. `loadMore()` — Increments page, calls fetchFoods(false) to append.
7. `setSearch(query: string)` — Sets searchQuery, calls fetchFoods(true).
8. `setCategory(cat: string | null)` — Sets selectedCategory, calls fetchFoods(true).
9. `toggleInactive()` — Toggles showInactive, calls fetchFoods(true).

Use `useApi().apiFetch` for all API calls. Handle errors with try/catch.
