**backend/db/queries/medications.sql** — Write all sqlc-annotated queries:

1. `CreateMedication` (:one) — INSERT into medications. Accept name, generic_name, form, dosage_unit, description, created_by. Compute `name_normalized = LOWER(normalize_persian(name))` and `generic_name_normalized = CASE WHEN generic_name IS NOT NULL THEN LOWER(normalize_persian(generic_name)) ELSE NULL END`. RETURNING *.

2. `GetMedicationByID` (:one) — SELECT m.*, u.full_name as creator_name FROM medications m JOIN users u ON m.created_by = u.id WHERE m.id = $1.

3. `ListMedications` (:many) — Query with optional search and active filter (per D-18, D-19):
   ```sql
   SELECT m.*, u.full_name as creator_name
   FROM medications m
   JOIN users u ON m.created_by = u.id
   WHERE m.is_active = COALESCE(sqlc.narg('is_active'), true)
     AND (sqlc.narg('search')::text IS NULL
       OR m.name_normalized ILIKE '%' || LOWER(normalize_persian(sqlc.narg('search')::text)) || '%'
       OR (m.generic_name_normalized IS NOT NULL
           AND m.generic_name_normalized ILIKE '%' || LOWER(normalize_persian(sqlc.narg('search')::text)) || '%'))
   ORDER BY
     CASE WHEN sqlc.narg('search')::text IS NOT NULL
       THEN similarity(m.name_normalized, LOWER(normalize_persian(sqlc.narg('search')::text)))
       ELSE 0 END DESC,
     m.created_at DESC
   LIMIT sqlc.arg('limit_val')
   OFFSET sqlc.arg('offset_val');
   ```

4. `CountMedications` (:one) — Same WHERE clause as ListMedications, SELECT COUNT(*).

5. `UpdateMedication` (:one) — UPDATE medications SET name, name_normalized, generic_name, generic_name_normalized, form, dosage_unit, description, updated_at WHERE id=$1 RETURNING *.

6. `SoftDeleteMedication` (:exec) — UPDATE medications SET is_active=false, updated_at=NOW() WHERE id=$1.

7. `SoftDeleteMedicationByOwner` (:exec) — UPDATE medications SET is_active=false, updated_at=NOW() WHERE id=$1 AND created_by=$2.

8. `CheckDuplicateMedicationName` (:one) — SELECT EXISTS(SELECT 1 FROM medications WHERE LOWER(normalize_persian(name)) = LOWER(normalize_persian($1)) AND is_active = true AND id != sqlc.narg('exclude_id')::uuid) AS is_duplicate.

Run `sqlc generate` after writing queries.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client/Nutritionist → /api/medications | Untrusted input: medication names, form types |
| Nutritionist → DELETE/UPDATE | Row-level auth: nutritionist can only modify own items |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-12 | Spoofing | medication_handler.go Create | mitigate | created_by set from JWT user_id, not request body |
| T-02-13 | Tampering | medication_handler.go Update | mitigate | Row-level auth: nutritionist=own items only. Super Admin bypass per D-29 |
| T-02-14 | Elevation | medication routes | mitigate | RoleGuard("nutritionist", "super_admin") blocks client role |
| T-02-15 | Injection | SQL queries | mitigate | All queries parameterized via sqlc (SEC-03) |
</threat_model>
