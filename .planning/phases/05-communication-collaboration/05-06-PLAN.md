## Context

Food request workflow: clients request foods to be added to the system; nutritionists approve (prefill food form) or reject with a reason.

## Tasks

### 1. Type definitions

**File**: `frontend/app/types/foodRequest.types.ts`

```typescript
export type FoodRequestStatus = 'pending' | 'approved' | 'rejected'

export interface FoodRequest {
  id: string
  food_name: string
  description: string | null
  status: FoodRequestStatus
  rejection_reason: string | null
  requested_by: string
  reviewed_by: string | null
  created_at: string
  updated_at: string
  client_name?: string  // included in nutritionist list view
}

export interface CreateFoodRequestPayload {
  food_name: string
  description?: string
}

export interface RejectFoodRequestPayload {
  rejection_reason?: string
}
```

```typescript
export const useFoodRequestStore = defineStore('foodRequest', () => {

  async function approveRequest(id: string) { ... }  // PATCH /api/nutritionist/food-requests/:id/approve
  async function rejectRequest(id: string, reason?: string) { ... }  // PATCH /api/nutritionist/food-requests/:id/reject
```

### 4. Nutritionist food requests page

**File**: `frontend/app/pages/nutritionist/food-requests.vue`

- `definePageMeta({ layout: 'nutritionist' })`
- Tab/filter: All | Pending | Approved | Rejected
- Each pending request card shows: client name, food_name, description, date
- Approve button: calls store.approveRequest, then uses `navigateTo('/nutritionist/foods/create?name=' + encodeURIComponent(request.food_name))`
